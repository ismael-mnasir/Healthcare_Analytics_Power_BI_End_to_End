# Healthcare Analytics — End-to-End Power BI Dashboard

## 📌 Project Overview
This project features an interactive, end-to-end Power BI dashboard designed to analyze healthcare data, patient admission dynamics, and operational efficiency across hospital departments. The goal is to provide actionable insights into patient care metrics, wait times, bed occupancy, and overall clinical trends.

---

## 🛠️ Key Features & Capabilities
* **Patient Demographics Analysis:** Breaks down admissions by age, gender, insurance provider, and medical condition.
* **Operational Performance:** Tracks average length of stay (LOS), admission types (Emergency vs. Elective), and readmission rates.
* **Interactive Navigation:** Includes custom slicers, dynamic cross-filtering, and drillthrough pages for granular patient-level insights.
* **Advanced DAX & Data Modeling:** Utilizes custom DAX measures for dynamic calculations and clean star-schema modeling.

---

## 🧰 Tools & Technologies
* **Tool:** Power BI Desktop
* **Data Transformation:** Power Query
* **Data Modeling & Analytics:** DAX (Data Analysis Expressions)
* **Version Control:** Git & GitHub
